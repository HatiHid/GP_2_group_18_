# GP_2_group_18_

### "Проект по недвижимости в Москве"

В этом проекте собран и обработан датасет по рынку недвижимости Москвы. Данные объединяют характеристики отдельных объявлений.

## Бизнес-задача

Определить оптимальный район Москвы для покупки квартиры с точки зрения баланса цены и развитости инфраструктуры ("цена/качество")

## Ход работы

Интерпретация показателя:

*  Низкое значение — оптимальное соотношение цены и качества (высокая инфраструктура при умеренной цене).
*  Высокое значение — жильё переоценено относительно качества инфраструктуры.

Таким образом, этот показатель позволяет оценить эффективность вложений и определить районы с лучшим балансом между стоимостью и уровнем инфраструктуры.

Чем меньше значение признака, тем лучше соотношени:

Низкая цена + высокое качество = низкий коэффициент - хорошо

Высокая цена + низкое качество = высокий коэффициент - плохо
