# GP_2_group_18_

### "Проект по недвижимости в Москве"

В этом проекте собран и обработан датасет по рынку недвижимости Москвы. Данные объединяют характеристики отдельных объявлений.

## Цель

Цель проекта —  провести анализ рынка недвижимости Москвы на основе открытых данных и данных, полученных через парсинг и API, с целью выявления закономерностей формирования цен, факторов, влияющих на стоимость квадратного метра, и определения наиболее благоприятных районов для покупки недвижимости

## Ход работы

1) Веб-скрапинг сайта move.ru
   
Для веб-скрапинга был выбран сайт move.ru, который содержит данные о квартирах в новостройках Москвы. В результате веб-скрапинга был получен  датасет, который имеет следующие признаки:

1. **price_millions** - цена квартиры (в млн. руб.).
   **тип** - вещественный
2. **complex_name** — название жилого комплекса.
   **тип:** категориальный
3. **developer** — название застройщика.
   **тип:** категориальный  
4. **housing_class** — сегмент жилья (эконом класс, комфорт класс и т.д.).
   **тип:** порядковый
5. **floor** — этаж квартиры.
   **тип:** порядковый
6. **total_floors** — общее количество этажей в новостройке.
   **тип:** категориальный
7. **rooms** — количество комнат в квартире.
   **тип:** порядковый
8. **total_area** — площадь квартиры (в м²).
   **тип:** вещественный
9. **living_area** — жилая площадь квартиры (в м²).
   **тип:** вещественный
10. **kitchen_area** — площадь кухни в квартире (в м²).
   **тип:** вещественный
11. **full_address** — адрес квартиры.
   **тип:** 
12. **metro_data** — данные о станциях метро рядом с квартирой (название и расстояние до станции).
   **тип:**
13. **metro_names** — названия станций метро, находящихся рядом с квартирой.
   **тип:**
14. **nearest_metro** — название ближайшей к квартире станции метро.
   **тип:** категориальный
15. **nearest_metro_distance** — расстояние до ближайшей станции метро.
   **тип:**
16. **views** — количество просмотров квартиры.
   **тип:** вещественный
17. **url** — ссылка на квартиру.
   **тип:**

Далее разделяем признак **full_address** на признаки city (город), okrug (административный округ), district (район) и other (всё, что идёт в адресе после района).

## **Кодирование**
  
 1. Кодирование класса жилья (housing_class_encoded) выполнено с помощью label-encoding, где более высокий класс получает большее числовое значение, а отсутствие информации о классе выделено в отдельную категорию. Интерпретация значений:

4 - премиум-класс

3 - элит-класс

2 - бизнес-класс

1 - комфорт-класс

0 - эконом-класс

-1 - отсутствует указание класса
